# 论文管理功能测试指南

> 创建时间：2026-03-22
> 测试环境：开发模式（Mock API）

---

## 🚀 快速启动

### 1. 启动 Mock API 服务器

```bash
# 在项目根目录
node complete-mock-api.js
```

服务器将在 `http://localhost:8082` 启动

### 2. 启动前端开发服务器

```bash
# 在 frontend 目录
cd frontend
npm run dev
```

前端将在 `http://localhost:5173` 启动

### 3. 访问论文管理页面

打开浏览器访问：`http://localhost:5173/papers`

## 🔍 API 端点测试

使用 curl 或 Postman 测试每个端点：

### 1. 获取论文列表

```bash
curl http://localhost:8082/api/papers
```

预期：返回4篇论文的数组

### 2. 创建论文

```bash
curl -X POST http://localhost:8082/api/papers \
  -H "Content-Type: application/json" \
  -d '{
    "title": "New Test Paper",
    "authors": "Test Author",
    "abstract": "Test abstract",
    "publication": "Test Journal",
    "year": "2024"
  }'
```

预期：返回新创建的论文，包含 id

### 3. 获取单个论文

```bash
curl http://localhost:8082/api/papers/1
```

预期：返回 id=1 的论文详情

### 4. 更新论文

```bash
curl -X PUT http://localhost:8082/api/papers/1 \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Updated Title"
  }'
```

预期：返回更新后的论文

### 5. 删除论文

```bash
curl -X DELETE http://localhost:8082/api/papers/1
```

预期：返回成功消息

### 6. 切换收藏

```bash
curl -X POST http://localhost:8082/api/papers/1/bookmark
```

预期：返回新的收藏状态

### 7. 标记已读

```bash
curl -X POST http://localhost:8082/api/papers/1/read \
  -H "Content-Type: application/json" \
  -d '{"isRead": true}'
```

预期：返回新的已读状态

### 8. 更新进度

```bash
curl -X POST http://localhost:8082/api/papers/1/progress \
  -H "Content-Type: application/json" \
  -d '{"progress": 50}'
```

预期：返回新的进度值

### 9. 获取统计

```bash
curl http://localhost:8082/api/papers/stats
```

预期：返回统计数据对象

### 10. 搜索论文

```bash
curl "http://localhost:8082/api/papers/search?q=attention"
```

预期：返回匹配的论文列表

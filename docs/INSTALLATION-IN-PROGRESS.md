## 💡 提示

### 组件说明

| 组件 | 作用 | 建议 |
|------|------|------|
| **MinGW 11.2.0 64-bit** | C++编译器 | ⭐ 必选 |
| **Qt Charts** | 图表组件 | ⭐ 推荐 |
| MSVC 2019 64-bit | 另一个编译器 | 可选 |
| Qt Creator | Qt官方IDE | 可选 |
| CMake | 构建工具 | 可选 |

### 最小安装方案

如果磁盘空间紧张，只安装必需组件：
- Qt 6.5.0
  - MinGW 11.2.0 64-bit
- Qt Charts

安装大小：约 2-3GB

## 📞 安装问题？

### 常见问题

**Q: 安装速度慢**
- 可以使用国内镜像源
- 或者先使用Web版本

**Q: 磁盘空间不足**
- 只安装必需组件（见上表）
- 安装到E盘或D盘

**Q: 组件选择困惑**
- 参考上方的组件说明表
- MinGW和Qt Charts是必需的

## 🆘 问题排查

### 如果无法访问：

1. **检查服务器状态**
   ```bash
   netstat -ano | findstr "5173"
   netstat -ano | findstr "3006"
   ```

2. **清除浏览器缓存**
   - 按 `Ctrl + Shift + Delete`
   - 选择"缓存的图像和文件"
   - 点击"清除数据"

3. **刷新页面**
   - 按 `Ctrl + F5` 或 `Cmd + Shift + R`

4. **检查防火墙**
   - 确保端口 5173 和 3006 未被阻止

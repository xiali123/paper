# Qt6 安装 - 开始安装

## 🎯 三步安装法

### 第1步：运行安装助手 📥

```bash
双击运行: install-qt6.bat
```

**这个脚本会**：
- ✅ 自动下载Qt安装程序（100MB）
- ✅ 启动安装向导
- ✅ 提供详细的步骤指导

---

### 第2步：按向导安装 ⚙️

#### 关键组件选择

```
请确保勾选以下组件：
┌──────────────────────────────────┐
│ ☑ Qt 6.5.0                     │
│   └─ ☑ MinGW 11.2.0 64-bit ⭐ │
│ ☑ Qt Charts ⭐                 │
│ ☑ CMake                        │
└──────────────────────────────────┘
```

**推荐设置**：
- 安装目录: `E:\Qt`
- 许可: 开源使用者
- 组件: 见上图

---

### 第3步：配置并编译 🔧

#### 自动配置

```bash
# 安装完成后运行
configure-qt-path.bat
```

这会自动：
- 🔍 搜索Qt安装位置
- ⚙️ 设置环境变量
- ✅ 验证配置

#### 开始编译

```bash
# 配置完成后运行
build-desktop.bat
```

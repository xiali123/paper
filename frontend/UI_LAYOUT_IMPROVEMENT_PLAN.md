# UI布局改进方案

## 问题分析

### 1. LaTeX编辑器工具栏问题
**现状**：
- 按钮拥挤在一行
- 缺少视觉分组
- 操作优先级不明确
- 移动端适配差

**改进方向**：
- 按功能分组（文件、编辑、视图、工具）
- 使用分隔符或间距区分
- 高频操作突出显示
- 低频操作收纳到下拉菜单

### 2. 主布局结构问题
**现状**：
- 顶部导航 + 侧边栏 + 面包屑占用空间过多
- 内容区域实际可用空间小
- 层级不够清晰

**改进方向**：
- 精简面包屑导航
- 优化侧边栏折叠交互
- 增加内容区域密度

## 改进方案

### A. LaTeX编辑器工具栏重构

#### 新布局结构
```
┌─────────────────────────────────────────────────────────┐
│ 📄 协作写作 / LaTeX / 文档名    [保存] [编译] [预览]  ⋮ │
├─────────────────────────────────────────────────────────┤
│ [+文件] [编辑] [插入] [≡更多]    [统计] [设置] [帮助] │
└─────────────────────────────────────────────────────────┘
```

#### 改进要点
1. **第一行**：核心操作 + 文档信息
   - 左侧：面包屑（简化版）
   - 右侧：高频操作（保存、编译、预览）

2. **第二行**：工具栏
   - 分组清晰：文件 | 编辑 | 插入 | 更多
   - 常用工具：统计、设置、帮助

### B. 主布局优化

#### 改进前
```
┌─────────────┬──────────────────────────────────────┐
│ TopNav      │                                       │
├─────────────┼──────────────────────────────────────┤
│             │ Breadcrumb                            │
│ Sidebar     ├──────────────────────────────────────┤
│             │ Main Content                          │
│             │                                       │
│             │                                       │
├─────────────┼──────────────────────────────────────┤
│             │ Footer                                │
└─────────────┴──────────────────────────────────────┘
```

#### 改进后
```
┌──────────────────────────────────────────────────────┐
│ 🏠 Home | 📄 Papers | ✍️ Writing   [🔍] [🔔] [👤]    │
├──────┬─────────────────────────────────────────────┤
│      │ Content Area                                 │
│      │                                             │
│ Side │                                             │
│ bar  │                                             │
│      │                                             │
│      │                                             │
└──────┴─────────────────────────────────────────────┘
```

#### 改进要点
1. **顶部导航扁平化**：移除多余层级
2. **面包屑内联化**：放在内容区顶部
3. **侧边栏可折叠**：默认折叠，点击展开
4. **移除页脚**：节省空间

### C. 响应式优化

#### 桌面端 (≥1400px)
- 完整布局
- 侧边栏展开
- 所有工具栏显示

#### 平板端 (768px - 1399px)
- 侧边栏默认折叠
- 工具栏精简
- 保持核心功能

#### 移动端 (<768px)
- 底部导航栏替代侧边栏
- 工具栏收纳到菜单
- 单列布局

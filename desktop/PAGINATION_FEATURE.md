# 桌面客户端分页功能

## ✅ 新增功能

### 1. 动态分页控制
- **每页显示数量选择**: 10、20、50、100 条
- **分页按钮**: 第一页、上一页、下一页、最后一页
- **页码显示**: 显示当前页/总页数（共 XX 篇）

### 2. 界面组件

#### 分页栏 (Pagination Bar)
```
┌─────────────────────────────────────────────────────────┐
│ 每页显示: [20 条 ▼]    第 1 / 3 页 (共 50 篇)    ⏮ ◀ ▶ ⏭ │
└─────────────────────────────────────────────────────────┘
```

#### 按钮说明
| 按钮 | 功能 | 快捷键提示 |
|------|------|-----------|
| **⏮** | 跳转到第一页 | 第一页 |
| **◀** | 上一页 | 上一页 |
| **▶** | 下一页 | 下一页 |
| **⏭** | 跳转到最后一页 | 最后一页 |

#### 下拉选择
| 选项 | 说明 |
|------|------|
| 10 条 | 每页显示 10 篇论文 |
| 20 条 | 每页显示 20 篇论文（默认） |
| 50 条 | 每页显示 50 篇论文 |
| 100 条 | 每页显示 100 篇论文 |

## 🎯 使用方法

### 基本操作

1. **搜索论文**
   - 在搜索框输入关键词
   - 点击"搜索"按钮
   - 显示第一页结果

2. **切换每页数量**
   - 点击"每页显示"下拉框
   - 选择 10/20/50/100 条
   - 自动重新加载第一页

3. **翻页**
   - 点击 **◀** 查看上一页
   - 点击 **▶** 查看下一页
   - 点击 **⏮** 跳转到第一页
   - 点击 **⏭** 跳转到最后一页

### 按钮状态

| 情况 | 第一页 | 上一页 | 下一页 | 最后一页 |
|------|--------|--------|--------|----------|
| **第 1 页** | 禁用 ❌ | 禁用 ❌ | 启用 ✅ | 启用 ✅ |
| **中间页** | 启用 ✅ | 启用 ✅ | 启用 ✅ | 启用 ✅ |
| **最后一页** | 启用 ✅ | 启用 ✅ | 禁用 ❌ | 禁用 ❌ |
| **只有 1 页** | 禁用 ❌ | 禁用 ❌ | 禁用 ❌ | 禁用 ❌ |

## 📊 数据流

```
用户搜索 "deep learning"
    ↓
MainWindow::onSearch("deep learning")
    ↓
保存状态: currentKeyword_ = "deep learning"
          currentOffset_ = 0
          currentLimit_ = 20
    ↓
ApiManager::searchPapers("deep learning", "", "", 0, 20)
    ↓
后端返回: 50 篇论文（前 20 篇）
    ↓
MainWindow::onSearchSuccess(result)
    ↓
totalResults_ = 50
    ↓
PaperCardView::setPapers(papers, 50)
    ↓
显示分页栏: "第 1 / 3 页 (共 50 篇)"
    ↓
用户点击"下一页"
    ↓
PaperCardView::pageChanged(20, 20)
    ↓
MainWindow::onPageChanged(20, 20)
    ↓
ApiManager::searchPapers("deep learning", "", "", 20, 20)
    ↓
后端返回: 第 21-40 篇论文
```

## 💡 技术实现

### 关键类

#### PaperCardView
- 新增信号: `pageChanged(int offset, int limit)`
- 新增方法:
  - `updatePaginationControls()` - 更新按钮状态
  - `onPageSizeChanged(int)` - 处理每页数量变化
  - `onFirstPage()` / `onPrevPage()` / `onNextPage()` / `onLastPage()` - 分页操作

#### MainWindow
- 新增成员变量:
  - `currentKeyword_` - 当前搜索关键词
  - `currentOffset_` - 当前偏移量
  - `currentLimit_` - 当前每页数量
  - `totalResults_` - 总结果数
- 新增槽函数: `onPageChanged(int offset, int limit)`

### API 调用

```cpp
// 搜索第一页（默认 20 条）
apiManager->searchPapers(keyword, "", "", 0, 20);

// 搜索第二页
apiManager->searchPapers(keyword, "", "", 20, 20);

// 搜索第三页（每页 50 条）
apiManager->searchPapers(keyword, "", "", 100, 50);
```

## 📝 示例场景

### 场景 1: 搜索并翻页

```
1. 输入 "test" → 搜索
   → 显示: 第 1 / 3 页 (共 50 篇)
   → 显示 20 篇论文

2. 点击 "▶" (下一页)
   → 显示: 第 2 / 3 页 (共 50 篇)
   → 显示 20 篇论文

3. 点击 "▶" (下一页)
   → 显示: 第 3 / 3 页 (共 50 篇)
   → 显示 10 篇论文
   → "下一页"和"最后一页"按钮禁用
```

### 场景 2: 修改每页数量

```
1. 当前: 第 2 / 5 页 (共 50 篇)，每页 10 条

2. 选择每页 50 条
   → 自动跳转回第一页
   → 显示: 第 1 / 1 页 (共 50 篇)
   → 显示全部 50 篇论文
   → 所有分页按钮禁用
```

## ⚙️ 配置选项

### 默认设置
- 默认每页数量: **20 条**
- 可选数量: 10, 20, 50, 100
- 窗口大小: 1400×900

### 修改默认值

如需修改默认每页数量，编辑 `PaperCardView.cpp`:

```cpp
// 在 setupUI() 中修改
pageSizeCombo_->setCurrentIndex(1);  // 0=10, 1=20, 2=50, 3=100
```

## 🐛 注意事项

1. **网络延迟**: 每次翻页都需要新的 API 请求
2. **后端限制**: 确保后端支持 offset 和 limit 参数
3. **状态保持**: 切换每页数量会重置到第一页
4. **搜索关键词**: 分页时保持原搜索关键词不变

## 2. 模块自动发现和加载流程

```
开始
  │
  ↓
┌─────────────────────────────────────┐
│ 1. PluginManager::scanAndLoadModules()
│    扫描 modules/dynamic/ 目录
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 2. 发现所有 .dll 文件                │
│    - libAuthApiModule.dll           │
│    - libPaperApiModule.dll          │
│    - libUserApiModule.dll           │
│    - libAiApiModule.dll             │
│    - libSearchApiModule.dll         │
│    - libExportApiModule.dll         │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 3. 对每个DLL:                        │
│    a. 提取模块名                     │
│       libAuthApiModule.dll           │
│       ↓ 去掉lib前缀                  │
│       AuthApiModule.dll              │
│       ↓ 去掉.dll后缀                 │
│       AuthApiModule                  │
│       ↓ 首字母大写                   │
│       AuthApiModule                  │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 4. 加载DLL                          │
│    LoadLibrary("libAuthApiModule.dll")│
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 5. 获取导出函数                      │
│    GetSymbol("createModule")         │
│    GetSymbol("destroyModule")        │
│    GetSymbol("getModuleVersion")     │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 6. 创建模块实例                      │
│    createModule() → IModule*         │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 7. 获取模块依赖                      │
│    module->getDependencies()         │
│    例如: ["DatabaseModule"]          │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 8. 依赖解析（拓扑排序）               │
│    按依赖顺序排列模块                 │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 9. 初始化模块                        │
│    module->initialize()              │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 10. 注册路由                         │
│     module->registerRoutes()         │
│     ↓                                │
│     Router::getInstance().post(      │
│       "/api/auth/login",             │
│       handler                        │
│     )                                │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 11. 启动模块                         │
│     module->start()                  │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 12. 重复步骤3-11，直到所有模块加载完成│
└─────────────────────────────────────┘
  │
  ↓
完成
```

## 3. HTTP请求处理流程

```
客户端请求
  POST /api/auth/login
  {"username": "test", "password": "test"}
  │
  ↓
┌─────────────────────────────────────┐
│ HTTP Server (端口8080)               │
│ 接收TCP连接                          │
│ 解析HTTP请求                         │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ Router::route(request)               │
│ 路由匹配:                            │
│ - 方法: POST                         │
│ - 路径: /api/auth/login              │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 查找路由表                           │
│ routes_[{POST, /api/auth/login}]    │
│ 找到匹配的handler                    │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ AuthApiModule::handleLogin(req)      │
│ - 解析JSON请求体                     │
│ - 验证用户名密码                     │
│ - 生成JWT token                      │
│ - 构造响应                           │
└─────────────────────────────────────┘
  │
  ↓
┌─────────────────────────────────────┐
│ 返回响应                             │
│ {                                   │
│   "access_token": "...",            │
│   "refresh_token": "...",           │
│   "token_type": "Bearer",           │
│   "expires_in": 3600                │
│ }                                   │
└─────────────────────────────────────┘
  │
  ↓
客户端接收响应
```

## 5. 模块命名和路由映射

```
┌─────────────────────────────────────────────────────────────────┐
│ DLL文件名            → 模块名            → 路由前缀              │
├─────────────────────────────────────────────────────────────────┤
│ libAuthApiModule.dll  → AuthApiModule     → /api/auth           │
│ libPaperApiModule.dll → PaperApiModule    → /api/papers         │
│ libUserApiModule.dll  → UserApiModule     → /api/users          │
│ libAiApiModule.dll    → AiApiModule       → /api/ai             │
│ libSearchApiModule.dll→ SearchApiModule   → /api/search         │
│ libExportApiModule.dll→ ExportApiModule   → /api/export         │
└─────────────────────────────────────────────────────────────────┘

命名规则转换:
1. 移除 "lib" 前缀
2. 移除扩展名 (.dll/.so)
3. 首字母大写
4. 转换为小写 + kebab-case
5. 添加 "/api/" 前缀
```

## 7. 热插拔场景

```
场景1: 运行时加载新模块

系统运行中...
  │
  ↓
管理员将 libNewModule.dll 放入 modules/dynamic/
  │
  ↓
调用 PluginManager::loadModule("NewModule", "modules/dynamic/libNewModule.dll")
  │
  ↓
┌─────────────────────────────────────┐
│ 1. LoadLibrary("libNewModule.dll")  │
│ 2. createModule()                   │
│ 3. module->initialize()             │
│ 4. module->registerRoutes()         │
│ 5. module->start()                  │
└─────────────────────────────────────┘
  │
  ↓
新模块立即可用，无需重启系统
  │
  ↓
客户端可以访问 /api/new/* 的路由


场景2: 运行时卸载模块

系统运行中...
  │
  ↓
调用 PluginManager::unloadModule("OldModule")
  │
  ↓
┌─────────────────────────────────────┐
│ 1. module->stop()                   │
│ 2. module->cleanup()                │
│ 3. Router::unregisterModuleRoutes() │
│ 4. destroyModule()                  │
│ 5. FreeLibrary(handle)              │
└─────────────────────────────────────┘
  │
  ↓
模块被安全卸载，其他模块继续工作
  │
  ↓
客户端访问 /api/old/* 返回404
```

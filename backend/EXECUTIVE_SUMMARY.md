# PaperCrawler 热插拔架构 - 执行摘要

## 🎯 项目目标

将PaperCrawler后端从**单体架构**重构为**热插拔架构**，实现：

- **main.cpp从3890行精简到<300行** (减少92%)
- **编译时间从120秒减少到30秒** (减少75%)
- **新增模块工作量减少90%**
- **支持运行时热插拔模块**
- **完全解耦，模块独立开发测试**

---

## 💡 核心方案

### 架构模式

```
热插拔架构 = 自动发现 + 动态加载 + 路由自注册
```

### 关键设计

1. **模块自动发现** - 扫描`modules/dynamic/`目录，自动加载所有`.dll`文件
2. **路由自动注册** - 每个模块实现`registerRoutes()`方法，自行注册路由
3. **依赖管理** - 支持模块依赖声明和自动解析（拓扑排序）
4. **故障隔离** - 单个模块失败不影响其他模块
5. **零配置** - 模块名自动映射到路由前缀

## 🏗️ 技术架构

### 核心组件

```
main.cpp (<300行)
  ↓
PluginManager::scanAndLoadModules("modules/dynamic/")
  ↓
自动发现所有.dll文件
  ↓
加载模块 → module->initialize() → module->registerRoutes()
  ↓
Router自动接收所有路由
  ↓
HTTP服务器启动，完全解耦
```

### 模块示例

```
libAuthApiModule.dll    → /api/auth/*
libPaperApiModule.dll   → /api/papers/*
libUserApiModule.dll    → /api/users/*
libAiApiModule.dll      → /api/ai/*
libSearchApiModule.dll  → /api/search/*
libExportApiModule.dll  → /api/export/*
```

## 2. 请求处理流程图

```
客户端请求
    │
    ▼
┌─────────────────────┐
│ HttpServerModule    │  ← HTTP解析, Keep-Alive
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  FilterModule       │  ← CORS, 认证, 速率限制, 日志
│  (过滤器链)         │
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  Router             │  ← 路由匹配, 参数提取
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  MessagePool        │  ← 预分配消息对象 (97%复用率)
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  PoolCoordinator    │  ← 负载均衡 (轮询/最少任务/随机)
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  ThreadPool         │  ← 工作线程处理
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  BusinessModule     │  ← 业务逻辑执行
│  (Auth/Paper/...)   │
└─────────┬───────────┘
          │
          ├──────────┐
          │          │
          ▼          ▼
    ┌─────────┐  ┌──────────────┐
    │Database │  │ MultiLevel   │
    │Module   │  │ Cache        │
    └────┬────┘  └──────────────┘
         │
         ▼
    MySQL/Redis
          │
          ▼
┌─────────────────────┐
│  ResponseQueue      │  ← 响应队列 (优先级排序)
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  ResponseHandler    │  ← JSON格式化, 压缩
└─────────┬───────────┘
          │
          ▼
    客户端响应
```
